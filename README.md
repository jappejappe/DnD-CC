# DnD-CC
D&amp;D 5E Coin Converter

## Linux

Ambiente de instalação
``` 
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

Variáveis de ambiente
```
echo 'BOT-TOKEN=' > .env
```
> Insira seu token depois do "="




## Windows
Ambiente de instalação
``` 
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

Variáveis de ambiente
```
'BOT_TOKEN=' > .env
```
> Insira seu token depois do "="
